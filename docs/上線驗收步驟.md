# 上線驗收：實際走一次主要流程

入庫 → 波次出貨（手機揀貨）→ 調撥 → 盤點，約 30 分鐘。
**只動一個「測試品」**，不會影響真實庫存；最後用盤點把測試品清成 0。

這份步驟和自動測試 `tests/ui/flow14-acceptance.mjs` 完全相同（已在測試環境跑過、全部通過）。

## 準備

| 項目 | 說明 |
|---|---|
| 電腦 | 開正式網址，用**倉管**帳號登入 |
| 手機 | 開 `正式網址/m/`，用**另一個**帳號登入（例如堆高機手） |
| 測試訂單 | `docs/acceptance-test-order.xlsx`（測試品 30 件、黑貓） |
| 儲位 | 找 3 個目前**空的**儲位，以下用 I-A-01-1F、I-A-02-1F、I-A-03-1F 代表，請換成你的 |
| 外倉 | 「外倉管理」裡至少要有一個外倉（調撥用），以下叫「測試外倉」 |

**先建立測試品**：電腦 →「品項主檔」→ 品號 `TEST001`、品名 `測試品`、規格 `TEST`、公司 崇文 → 儲存。

每一步做完，在「庫存查詢」或手機「庫存快查」打 `測試品` 對數字。

---

## 1. 入庫

### 1a. 交給堆高機 → 手機上架即入帳

1. 電腦登入後是「今日工作」→ 點「入庫」
2. 入庫類型選 **成品**（在公司別下面；選「採購」會送財務對帳）
3. 點品名選 **測試品**；批號 `TEST01`；效期 `2027/12/31`；數量 **50**；儲位 **I-A-01-1F**
4. 右邊按「🚜 **交給堆高機**」→ 確認訊息會寫清楚品項、數量、儲位 → 確定
5. 手機主選單「入庫任務」出現紅色 1 → 點進去 → 點這筆任務
6. 手機掃（或打）儲位 **I-A-01-1F**

✅ 預期：手機顯示「已入庫」；庫存查詢：測試品 **50 件 @ I-A-01-1F**；電腦「今日工作」的「待入帳入庫單」回到 0。

> 順便試：第 6 步掃一個**不同**的儲位 → 手機會問「放的儲位和指定的不同，以實際儲位入帳？」

### 1b. 直接入庫到暫存區 → 手機上架

1. 電腦「智能入庫中心」：成品、測試品、數量 **20**、儲位 **TEMP-IN** →「📦 **馬上入帳**」
2. 手機「上架」→ 儲位打 `IA021`（= I-A-02-1F，縮寫也可以）
3. 棧板：打剛入庫板號的**最後 3 碼**（或掃棧板單）→ 確認上架

✅ 預期：測試品 **20 件 @ I-A-02-1F**，TEMP-IN 沒有測試品。合計 **70**。

## 2. 波次出貨（手機揀貨）

1. 電腦「今日工作」→ 點「出貨」（波次揀貨）→ 公司「崇文」→「匯入訂單」→ 選 `acceptance-test-order.xlsx`（畫面上方的步驟列會亮在目前這一步）
2. 出現「匯入完成…是否要自動依物流商建立波次？」→ 確定
3. 手機「波次揀貨」→ 選剛建立的波次（黑貓）
4. 清單顯示要揀的板與儲位 → 按綠色 📷 對準**棧板單或儲位標籤**連續掃（或手打板號尾碼）
5. 全部打勾 → 「完成波次（扣庫存出貨）」→ 確定

✅ 預期：測試品剩 **40**（先揀效期早的／依動線）；電腦波次狀態「已完成」、訂單 TEST-SO-001「已出貨」。

> 順便試：同一板再掃一次 → 「已揀過」；手機揀到一半時，電腦開同一個波次，應該看到相同的打勾進度。

## 3. 調撥

### 3a. 調撥出庫（本倉 → 外倉）

1. 電腦「倉庫調撥」→「調撥出庫」→ 目標選 **測試外倉**
2. 「選擇品項」→ 測試品 → 數量 **10** → 加入 →「確認執行調撥」

✅ 預期：本倉測試品 **30**；「外倉管理」測試外倉有測試品 **10**；TEMP-OUT 沒有多出一板。

### 3b. 調撥入庫（外倉 → 本倉）→ 手機上架

1. 電腦「倉庫調撥」→「調撥入庫」→ 來源選 **測試外倉** → 測試品 **10** → 處理方式選「產生待執行工單」（會發到手機）→ 確認執行
2. 手機「入庫任務」出現一筆（儲位「待指定」）→ 點它 → 掃 **I-A-03-1F**

✅ 預期：外倉測試品歸 0；本倉測試品 **10 件 @ I-A-03-1F**，合計 **40**。

## 4. 盤點

### 4a. 電腦盤點

1. 電腦「庫存盤點」→ 區域 **I-A**、排 **1 ~ 3** →「載入盤點清單」（可以按「列印盤點表」看格式）
2. I-A-01-1F 的測試品，實盤輸入「帳面 − 1」
3. 「未盤的照帳面」→「送出盤點」

✅ 預期：只有這一板被調整（少 1 件），同範圍的其他真實庫存數量不變。

### 4b. 手機盤點＋清理

1. 手機「盤點」→ 掃測試品的板（或該儲位標籤）→ 實際數量輸入 **0** → 送出 → 確定刪除
2. 三板測試品都做一次

✅ 預期：庫存查詢打 `測試品` 找不到任何一板。

## 5. 最後檢查

- 電腦「異動查詢」搜 `測試品`：應看到入庫、移板、出庫、調撥、調整，每筆都有**操作人**
- 真實品項的數量沒有變動
- 測完可以到「品項主檔」把 測試品 刪掉
