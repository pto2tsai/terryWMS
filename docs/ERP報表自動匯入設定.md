# 鼎新報表自動匯入：設定步驟

## 整個流程

```
鼎新 COSMOS 定時輸出 Excel
   ↓ 存到電腦上的 Google 雲端硬碟（G 槽）「鼎新匯出」資料夾
Google 自動同步到雲端
   ↓
Google 雲端上的兩支小程式，每 10 分鐘看一次資料夾，各拿各的：
   ・WMS 的程式：每日客戶銷貨明細表 → WMS 自動匯入訂單、依物流商建好波次
   ・八方 ERP 的程式：4 種月報 → 八方 ERP 自己解析
```

處理完的檔案會自動搬到「已匯入／年-月」；看不懂或失敗的搬到「匯入失敗」，並寄 Email 通知。

---

## 設定（全部做一次就好，大約 20 分鐘）

**兩支程式都用同一個 Google 帳號設定**：建立兩個 Firebase 專案的那個帳號。

### 1. 匯出鼎新的那台電腦：裝 Google 雲端硬碟

用上面那個 Google 帳號，下載安裝「Google 雲端硬碟電腦版」並登入。電腦會多一個 G 槽。
這台電腦要一直開著、保持登入。

### 2. 設定 WMS 的程式

1. 打開 <https://script.google.com> → 按「新專案」。
2. 把 `tools/erp-sync/Code.gs` 整份貼上，取代原本的內容。
3. 左邊齒輪「專案設定」→ 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」。
   回到編輯器，打開 `appsscript.json`，把 `tools/erp-sync/appsscript.json` 整份貼上。
4. 上方選 **setup**，按「執行」，照畫面按「允許」。

完成後會寄一封信給你，寫著：
- ✅ 或 ❌ 每一項設定有沒有成功
- **鼎新要輸出到哪個路徑**（直接照抄到 COSMOS）

「鼎新匯出」資料夾和子資料夾會自動建好，不用自己建。

### 3. 設定八方 ERP 的程式

跟第 2 步一樣，再開一個新專案，貼的是 seafood-system 專案的 `tools/erp-sync/Code.gs` 和 `appsscript.json`，一樣選 **setup** 按「執行」。
它會沿用同一個「鼎新匯出」資料夾，再加 4 個月報的子資料夾，一樣寄信告訴你路徑。

### 4. 在 COSMOS 設定定時輸出

照兩封信上的路徑設定：

| 報表 | 輸出時間 | 條件 |
|---|---|---|
| 每日客戶銷貨明細表 | 每天 8:55、10:55、12:55、14:55 | **最近 7 天**的銷貨明細 |
| 商品銷貨期報表、每月客戶銷貨明細表、應收帳款明細表、領料明細表 | 每月 1 日 | 上個月 |

- 格式：Excel（.xlsx 或 .xls）。
- 每日客戶銷貨明細表要有這幾欄：銷貨單號、品名、銷貨數量、備註（寫物流商）。
- **為什麼是「最近 7 天」**：下午 3 點以後開的單、週末開的單，隔天才會被輸出到；重複的單系統會自動略過，不會重複建單。

### 5. 發布 WMS 的安全規則

Firebase 主控台（WMS 的專案）→ Firestore Database → 規則，把 `firestore.rules` 整份貼上，按「發布」。

### 6. 測試

把 COSMOS 的輸出時間暫時設成 5 分鐘後。15 分鐘內應該會：
- 「鼎新匯出／每日客戶銷貨明細表」出現檔案，接著被搬到「已匯入」
- WMS「查詢與報表 → ERP 報表（鼎新）」出現這份報表，狀態「完成」或「要處理」
- 「波次揀貨」出現自動建好的波次

## 每天會發生什麼

- **至少一台電腦開著 WMS 電腦版**（不是只讀帳號），訂單才會被匯入、建波次。
- 看板上方紅條、首頁「鼎新匯入要處理」會提醒：
  - 📭 **訂單檔沒收到**：過了預計時間 25 分鐘還沒收到。可能是鼎新沒輸出、那台電腦關機、雲端硬碟沒同步。
    預計時間可以在「ERP 報表（鼎新）」頁修改（主管）。
  - ⏳ **訂單檔等太久沒匯入**：沒有電腦開著 WMS。
  - ⚠️ **要處理**：到「ERP 報表（鼎新）」頁看右邊說明：
    - 件數換算不出來 → 按「手動匯入」填件數
    - 沒有物流商 → 到「波次揀貨 → 建立波次」選物流商
    - 鼎新的最新檔案裡沒有這些單（可能已在鼎新取消）→ 確認後按「在 WMS 也取消」。還沒開始揀的波次會自動移出這些單；已經開始揀的會列出來，請到現場處理
    - 已出貨的單在鼎新有修改 → 到鼎新處理

## 常見問題

- **檔案跑到「匯入失敗」**：看 Email 的原因（通常是認不出報表種類，或檔案是空的）。修正後放回原本的子資料夾就會再匯入。
- **同一個檔案、同一張單會不會重複？** 不會。
- **鼎新只能存到同一個資料夾、不能分子資料夾**：系統也會看檔名和報表標題認報表。認不出來的話，把檔名傳給工程人員，在程式的 `CODE_MAP` 補上代碼對照。
- **月報在哪裡看？** 在八方 ERP 裡看，不會進 WMS。
- **庫存明細、批號明細、外倉庫存要不要輸出？** 目前不用。之後做每天對帳時再開始輸出，WMS 的程式已經認得。
