# 鼎新報表自動匯入：設定步驟

## 整個流程

```
鼎新 COSMOS 定時輸出 Excel
   ↓ 存到電腦上的 Google 雲端硬碟（G 槽）「鼎新匯出」資料夾
Google 自動同步到雲端
   ↓
Google 雲端上的兩支小程式，每 10 分鐘看一次資料夾，各拿各的：
   ・WMS 的程式：每日客戶銷貨明細表 → WMS 自動匯入訂單、依物流商建好波次
   ・八方 ERP 的程式：4 種月報 → 八方 ERP 自己解析
```

處理完的檔案會自動搬到「已匯入／年-月」；看不懂或失敗的搬到「匯入失敗」，並寄 Email 通知。

---

## 設定（全部做一次就好，大約 20 分鐘）

**兩支程式都用同一個 Google 帳號設定**：建立兩個 Firebase 專案的那個帳號。

### 1. 匯出鼎新的那台電腦：裝 Google 雲端硬碟

用上面那個 Google 帳號，下載安裝「Google 雲端硬碟電腦版」並登入。電腦會多一個 G 槽。
這台電腦要一直開著、保持登入。

### 2. 設定 WMS 的程式

1. 打開 <https://script.google.com> → 按「新專案」。
2. 把 `tools/erp-sync/Code.gs` 整份貼上，取代原本的內容。
3. 左邊齒輪「專案設定」→ 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」。
   回到編輯器，打開 `appsscript.json`，把 `tools/erp-sync/appsscript.json` 整份貼上。
4. 上方選 **setup**，按「執行」，照畫面按「允許」。

完成後會寄一封信給你，寫著：
- ✅ 或 ❌ 每一項設定有沒有成功
- **鼎新要輸出到哪個路徑**（直接照抄到 COSMOS）

「鼎新匯出」資料夾和子資料夾會自動建好，不用自己建。

### 3. 設定八方 ERP 的程式

跟第 2 步一樣，再開一個新專案，貼的是 seafood-system 專案的 `tools/erp-sync/Code.gs` 和 `appsscript.json`，一樣選 **setup** 按「執行」。
它會沿用同一個「鼎新匯出」資料夾，再加 4 個月報的子資料夾，一樣寄信告訴你路徑。

### 4. 在 COSMOS 設定定時輸出

照兩封信上的路徑設定：

| 報表 | 輸出時間 | 條件 |
|---|---|---|
| 每日客戶銷貨明細表 | 每天 8:55、10:55、12:55、14:55 | **最近 7 天**的銷貨明細 |
| 商品銷貨期報表、每月客戶銷貨明細表、應收帳款明細表、領料明細表 | 每月 1 日 | 上個月 |

- 格式：Excel（.xlsx 或 .xls）。
- 每日客戶銷貨明細表要有這幾欄：銷貨單號、品名、銷貨數量、備註（寫物流商）。
- **為什麼是「最近 7 天」**：下午 3 點以後開的單、週末開的單，隔天才會被輸出到；重複的單系統會自動略過，不會重複建單。

### 5. 發布 WMS 的安全規則

Firebase 主控台（WMS 的專案）→ Firestore Database → 規則，把 `firestore.rules` 整份貼上，按「發布」。

### 6. 測試

把 COSMOS 的輸出時間暫時設成 5 分鐘後。15 分鐘內應該會：
- 「鼎新匯出／每日客戶銷貨明細表」出現檔案，接著被搬到「已匯入」
- WMS「查詢與報表 → ERP 報表（鼎新）」出現這份報表，狀態「完成」或「要處理」
- 「波次揀貨」出現自動建好的波次

## 每天會發生什麼

- **至少一台電腦開著 WMS 電腦版**（不是只讀帳號），訂單才會被匯入、建波次。
- 看板上方紅條、首頁「鼎新匯入要處理」會提醒：
  - 📭 **訂單檔沒收到**：過了預計時間 25 分鐘還沒收到。可能是鼎新沒輸出、那台電腦關機、雲端硬碟沒同步。
    預計時間可以在「ERP 報表（鼎新）」頁修改（主管）。
  - ⏳ **訂單檔等太久沒匯入**：沒有電腦開著 WMS。
  - ⚠️ **要處理**：到「ERP 報表（鼎新）」頁看右邊說明：
    - 件數換算不出來 → 按「手動匯入」填件數
    - 沒有物流商 → 到「波次揀貨 → 建立波次」選物流商
    - 鼎新的最新檔案裡沒有這些單（可能已在鼎新取消）→ 確認後按「在 WMS 也取消」。還沒開始揀的波次會自動移出這些單；已經開始揀的會列出來，請到現場處理
    - 已出貨的單在鼎新有修改 → 到鼎新處理

## 鼎新的訂單改了會怎樣（全部自動，現場照手機做就好）

| 訂單現在的狀態 | WMS 自動做什麼 | 人要做什麼 |
|---|---|---|
| 還沒排波次 | 改成鼎新的新內容 | 不用 |
| 在波次裡，還沒開始揀 | 波次數量一起更新 | 有印紙本的：波次清單上標「🖨️ 揀貨單要重印」，重印就好 |
| 在波次裡，**已經開始揀** | 手機清單自動調整：少的**補揀**；多拿的列「**↩️ 放回 N 件 → 哪一格**」排最上面；手機上方藍色提醒寫著改了什麼 | 照手機做。沒放回不能按完成；庫存照「揀的－放回的」扣 |
| 已經出貨，鼎新**加量** | 多的部分自動變「補出貨」，排進下一個波次 | 不用 |
| 已經出貨，鼎新**減量** | 提醒「已經多出貨了，請在鼎新開銷退」 | 在鼎新開銷退 |
| 鼎新把整張單刪了 | 提醒「可能已在鼎新取消」 | 確認後按「在 WMS 也取消」 |

自動處理好的（前四種）不會出現「要處理」，只記在「ERP 報表」頁的結果裡。

## 揀貨、缺貨、分貨標籤

- **開始揀貨**：電腦按「開始揀貨」會直接打開揀貨單的列印預覽（只有揀貨單）。匯入訂單建好波次時，也可以按「列印揀貨單」一次印全部新波次。
- **分貨標籤揀完才印**，件數是實際出貨的，不用手改。誰來印由主管在「波次揀貨」右上角切換「🏷️ 標籤」：
  - **手機印**（預設）：手機完成波次後按「🖨️ 印分貨標籤」，選 Wi-Fi 標籤機（iPhone 要支援 AirPrint）。一張訂單一張標籤。
  - **辦公室自動印**（手機連不上標籤機時）：在負責印的那台電腦勾「這台電腦自動印標籤」並保持開著；手機一完成，那台電腦就自動印。
    要完全不用按「列印」：Chrome 捷徑按右鍵 →「內容」→「目標」最後面空一格加上 `--kiosk-printing`，之後用這個捷徑打開 Chrome。
  - 要補印：波次清單上已完成的波次按 🖨️。
- **手機揀貨**：每一項拿好按「✓ 拿好了」；畫面會提醒「下一項」是什麼。
- **不夠**：按「⚠️ 不夠」，填實際拿到幾件（沒有貨填 0）。不夠的記成缺貨，不會再叫人去拿。
- **完成波次**（手機）：有品項不夠時，先列出「共訂幾件、只拿到幾件、要怎麼分」：
  - 每張訂單一個數字，預設先開單的先給，**現場可以改**；加起來要等於實際拿到的件數。
  - 每張訂單會寫「標籤改成幾件」，現場改好標籤、勾「標籤都改好了」才能完成。
  - 缺的貨**這次不出、之後也不補**，訂單照實際出的件數結案。
  - 電視看板、電腦首頁會顯示「缺貨少出：海霸王 白蝦 5→3，請業務在鼎新改銷貨單」。
  - 業務在鼎新改好數量，下次匯入後提醒**自動消失**；鼎新還沒改之前再匯入，也**不會**變成補出貨。
- 標籤上缺貨的品項會註明「缺貨：訂 5，出 3」。

## 練習模式（還沒有儲位、庫存還不準的時候）

電腦版「波次揀貨」右上角的「📝 練習模式」（主管才能切換）。打開後：

- 揀貨單照**訂單數量**列出，不看庫存、不標「庫存不足」，儲位欄寫「照訂單揀」
- 手機和電腦都是拿好了按「✓ 拿好了」（沒有板號可以掃）
- 完成波次**不扣庫存**，訂單照常標記出貨
- 自動匯入、建波次、鼎新改單的調整（包括「放回」）、分貨標籤、看板都照常

正式上線（盤點、匯入真正的儲位）之後再關掉。

### 練習庫存每天自動更新

練習模式開著時，每天寄來的庫存信（寄件人 bapbts0901@gmail.com、主旨有「庫存」）裡的「**批號庫存表**」會自動：

1. 被 WMS 的 Google 程式存進「鼎新匯出／批號明細表」（只讀信，不會改信、刪信）
2. WMS 電腦版收到後，把 **OTHER 儲位**的庫存改成跟鼎新一樣：
   - 只放「崇文一廠」「八方一廠」；外倉、寄庫倉、0 件的不放
   - 同一品號＋批號每天用同一個板號（PR 開頭），只更新件數；鼎新沒有的刪掉
   - 放在真正儲位的板不會動
3. 手機「庫存快查」就查得到最新的數字

練習模式關掉之後，收到的批號庫存表只存檔、不改庫存。

**要做一次**：這個功能要讀信，要把新版的 `tools/erp-sync/Code.gs` 和 `appsscript.json` 貼到 WMS 的 Google 程式（取代舊的），選 **setup** 再執行一次，照畫面允許「讀取 Gmail」。信上會多一行「✅ 找到庫存信」。

庫存信的寄件人或附件名稱改了，改 `Code.gs` 上面 `CONFIG.STOCK_MAIL` 的兩個字就好。

## 常見問題

- **檔案跑到「匯入失敗」**：看 Email 的原因（通常是認不出報表種類，或檔案是空的）。修正後放回原本的子資料夾就會再匯入。
- **同一個檔案、同一張單會不會重複？** 不會。
- **鼎新只能存到同一個資料夾、不能分子資料夾**：系統也會看檔名和報表標題認報表。認不出來的話，把檔名傳給工程人員，在程式的 `CODE_MAP` 補上代碼對照。
- **月報在哪裡看？** 在八方 ERP 裡看，不會進 WMS。
- **庫存明細、批號明細、外倉庫存要不要從鼎新輸出？** 目前不用。批號庫存表已經每天用 Email 寄來，程式會自己從信裡拿。
